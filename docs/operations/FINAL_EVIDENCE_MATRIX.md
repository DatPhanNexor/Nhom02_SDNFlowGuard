## 1. Tổng quan phương pháp kiểm chứng (Verification Methodology)

Tất cả các hình minh chứng (Figures 4.1 đến 4.15) được đối chiếu thực nghiệm trực tiếp dựa trên:
1. Trạng thái hạ tầng Container ảo hóa Docker Compose.
2. Bộ điều khiển SDN Controller ONOS 2.7 (REST API cổng `8181`, OpenFlow 1.3 cổng `6653`).
3. Mặt phẳng chuyển tiếp Mininet / Open vSwitch (OVS) gồm 6 switch, 9 host và 10 directed links.
4. Kho chỉ mục phân tán Elasticsearch (`sdnflowguard-events-*`) gồm 145 tài liệu.
5. Cơ sở dữ liệu kiểm toán SQLite cục bộ (`events`: 8 bản ghi, `actions`: 93 bản ghi).
6. Ứng dụng Frontend React SPA và Backend API Flask.

Nguyên tắc bất biến: **Không thay đổi timestamp gốc của bằng chứng lịch sử; mọi bằng chứng thực nghiệm mới đều có metadata và nguồn gốc rõ ràng; không nhầm lẫn giữa mô phỏng DRY_RUN với thực thi can thiệp mạng.**
